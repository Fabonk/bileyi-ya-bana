Cantique n° 316

Jubilé céleste

1Un beau matin nous verrons Jésus
Là dans les airs,
Venir pour vous et moi,
Nous partagerons la joie ;
Quelle joie ce sera quand les saints ressusciteront,
Se dirigeant tous vers le Ciel
Pour ce jubilé.

RefrainQuel jour de chants, quel jour de cris !
En ce beau matin de la résurrection ;
Ô quelle gloire, alléluia !
Nous rencontrerons le Seigneur
Dans les cieux.

2C’est comme si je peux voir tous les saints Morts ressuscités pour ce jubilé qui est si proche,
En un clin d’œil, être changé avec eux,
Tous les saints vivants s’envoler à ce jubilé.

3Lorsque nous chanterons avec toute
Cette armée céleste,
Chantant dans le Saint-Esprit,
Les cloches du Ciel sonneront,

4Des millions se joindront au chant,
Louant Christ pour toujours,
Jubilé du Ciel.
