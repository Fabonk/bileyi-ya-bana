Cantique n° 168

Es-tu lavé dans le sang?

Tonalité : Ab (la bémol)

1As-tu rencontré Jésus qui purifie?
Es-tu lavé dans le sang de l’Agneau?
As-tu pleinement confiance en Sa grâce maintenant ?
Es-tu lavé dans le sang de l’Agneau?

RefrainEs-tu lavé dans le sang,
De l’Agneau qui purifie les âmes?
Tes habits sont-ils purs, aussi blancs que neige?
Es-tu lavé dans le sang de l’Agneau?

2Marches-tu chaque jour à côté du Sauveur?
Es-tu lavé dans le sang de l’Agneau?
Demeures-tu toujours dans le Crucifié?
Es-tu lavé dans le sang de l’Agneau?

3Quand l’Epoux viendra, ta robe sera-t-elle blanche?
Pure et blanche dans le Sang de l’Agneau?
Ton âme sera-t-elle prête pour le beau palais,
Es-tu lavé dans le sang de l’Agneau?

4Débarrasse-toi de ces habits de péché,
Et sois lavé dans le sang de l’Agneau;
Il y a une fontaine qui coule pour l’âme impure;
Oh! sois lavé dans le sang de l’Agneau !
