Cantique n° 392

Loue soit le nom de Jésus

1Loué soit le Nom, (ter) De Jésus. ( bis)
Alléluia! (bis)
Béni soit le Nom de Jésus.

2Jésus est le Nom, (ter) De mon Dieu. ( bis)
Alléluia! (bis)
Jésus est le Nom de Mon Dieu.

3Puissance en le Nom (de Jésus)...(2x)
Alléluia! Alléluia!
Puissance en le Nom de Jésus.

4Salut en le Nom (de Jésus) ...(2x)
Alléluia! Alléluia!
Salut en le Nom de Jésus!

5La vie en le Nom (de Jésus) ...(2x)
Alléluia! Alléluia!
La vie en le Nom de Jésus
