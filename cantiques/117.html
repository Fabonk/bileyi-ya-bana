Cantique n° 117

Contemplet mon Dieu sur son trône…

1Contempler mon Dieu sur son trône,
Vivre avec Jésus dans le ciel, (dans le ciel) Jeter à ses pieds ma couronne,
C’est là le bonheur éternel.
(Dans le ciel).

RefrainDans le ciel, (dans le ciel),
Dans le ciel, (dans le ciel),
Vivre avec Jésus dans le ciel, (dans le ciel),
Dans le ciel, (dans le ciel), dans le ciel, dans le ciel, c’est là le bonheur éternel.

2Unir ma voix aux chœurs des anges,
Bénir, louer Emmanuel,
(dans le ciel),
Chanter à jamais ses louanges,
C’est là le
bonheur éternel. (Dans le ciel),

3Jouir d’une paix infinie,
Revoir mes amis dans le ciel, (dans le ciel),
Posséder l’immortelle vie,
C’est là le bonheur éternel.
(Dans le ciel),

4Retrouver les saints dans la gloire,
Près du trône de l’Eternel, (dans le ciel),
Célébrer la même victoire.
C’est là le bonheur éternel.
(Dans le ciel)
