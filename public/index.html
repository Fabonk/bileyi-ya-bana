Installer

Sur AndroidTéléphone ou tablette
  1. Téléchargez l’APK sur le téléphone.
  2. Ouvrez le fichier téléchargé, depuis la notification ou l’application Fichiers.
  3. Si le téléphone le demande, touchez Paramètres et autorisez l’installation depuis cette source, puis revenez en arrière.
  4. Touchez Installer. Si Play Protect affiche un avertissement, choisissez de l’installer quand même : l’application ne vient simplement pas du Play Store.
Sur iPhone ou iPadSans ordinateur, avec Safari

L’application s’ajoute à l’écran d’accueil depuis Safari : ni ordinateur, ni compte Apple, ni fichier à installer.

  1. Sur l’iPhone, dans Safari, ouvrez la bibliothèque : Ouvrir la bibliothèque
  2. Touchez Partager (le carré avec une flèche vers le haut), puis Sur l’écran d’accueil. S’il n’apparaît pas, faites défiler la liste vers le bas.
  3. Touchez Ajouter : l’icône Bileyi ya Bana apparaît sur l’écran d’accueil. Ouvrez l’application depuis cette icône.
  4. Pour tout lire sans internet, touchez Tout télécharger sur sa page d’accueil (de préférence en Wi-Fi). Sinon, les pages déjà ouvertes restent lisibles hors connexion.

L’application se met à jour toute seule. Pour les habitués de Sideloadly, le fichier IPA reste disponible : BILEYI-YA-BANA-1.2.1-iphone.ipa (163 Mo, à installer depuis un ordinateur).

Sur WindowsWindows 10 ou 11, 64 bits
  1. Téléchargez l’installateur et ouvrez-le.
  2. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur Informations complémentaires puis Exécuter quand même.
  3. Suivez l’assistant. L’application apparaît ensuite dans le menu Démarrer, et sur le bureau si vous l’avez choisi.

Sur certains Windows 10, l’application demande d’abord le composant Microsoft WebView2 : acceptez, elle ouvre la page de téléchargement de Microsoft.
